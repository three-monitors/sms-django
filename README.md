# Beauty Clinic — Django версія
Система управління салоном краси на Django.

## Installation
```bash
python -m venv .venv
.venv\Scripts\activate
pip install django
cd myproject
python manage.py runserver
```

## Features
- Головна сторінка
- Список клієнтів
- Деталі клієнта з замовленнями
- Список послуг
- Деталі послуги
- Список замовлень
- Деталі замовлення
- Сторінка "Про проєкт"

## Сторінки

### Головна сторінка (/)
Показує заголовок "Головна сторінка" та опис системи управління салоном краси.

### Клієнти (/clients/)
Показує заголовок "Клієнти" та таблицю клієнтів.

### *Деталі клієнта* (/clients/id/)
Показує деталі окремого клієнта і деталі його замовлення.

### Послуги (/services/)
Показує заголовок "Послуги" та таблицю послуг.

### *Деталі послуги* (/services/id/)
Показує назву послуги і деталі окремої послуги.

### Замовлення (/orders/)
Показує заголовок "Замовлення" та таблицю замовлень.

### *Деталі замовлення* (/orders/id/)
Показує деталі окремого замовлення.

### Про проєкт (/about/)
Показує заголовок "Про проєкт" та інформацію про Django реалізацію Beauty Clinic.

## Автентифікація

### Реєстрація (/register/)
Можна зареєструвати нового користувача. Для реєстрації потрібно ввести:
- Логін (username)
- Пароль
- Підтвердження пароля

Після успішної реєстрації користувач автоматично входить в систему.

### Вхід в систему (/login/)
Для тестування використовуйте:

**Адміністратор (доступ до адмін-панелі)**
- Username: admin
- Password: admin / встановлено при створенні суперкористувача

**Менеджер (повний доступ через адмінку)**
- Username: manager
- Password: managerpassword / створено через Django Admin для перевірки дозволів

**Редактор (обмежений доступ через адмінку)**
- Username: editor
- Password: editorpassword / створено через Django Admin для перевірки дозволів

** Тестові дані для превірки, не для використання в реальному проєкті.

### Захищені сторінки
- `/profile/` — профіль користувача (тільки авторизовані)
- `/my-orders/` — мої замовлення (тільки авторизовані)

### Захист функціоналу
- Створення замовлень доступно тільки авторизованим користувачам
- Редагування замовлень доступно тільки автору або суперкористувачу
