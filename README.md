# Beauty Clinic — Django версія
Система управління салоном краси на Django.

## Installation
```bash
python -m venv .venv
.venv\Scripts\activate
pip install django
cd myproject
python manage.py runserver
```

## Features
- Головна сторінка
- Список клієнтів
- Деталі клієнта з замовленнями
- Список послуг
- Деталі послуги
- Список замовлень
- Деталі замовлення
- Сторінка "Про проєкт"

## Сторінки

### Головна сторінка (/)
Показує заголовок "Головна сторінка" та опис системи управління салоном краси.

### Клієнти (/clients/)
Показує заголовок "Клієнти" та таблицю клієнтів.

### *Деталі клієнта* (/clients/id/)
Показує деталі окремого клієнта і деталі його замовлення.

### Послуги (/services/)
Показує заголовок "Послуги" та таблицю послуг.

### *Деталі послуги* (/services/id/)
Показує назву послуги і деталі окремої послуги.

### Замовлення (/orders/)
Показує заголовок "Замовлення" та таблицю замовлень.

### *Деталі замовлення* (/orders/id/)
Показує деталі окремого замовлення.

### Про проєкт (/about/)
Показує заголовок "Про проєкт" та інформацію про Django реалізацію Beauty Clinic.
